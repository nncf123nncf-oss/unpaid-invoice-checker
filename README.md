# 入金チェック

請求の一覧と銀行の入金明細（CSVファイル、または貼り付けた文字）を入れると、貼られた明細の中に入金が見当たらない請求だけを、期日の超過日数つきで一覧にして、確認の連絡文（LINE・メール）まで作るWebページです（100日100プロダクト Day065）。

- 入力した内容はブラウザの中だけで処理します。送信も保存もしません（ページを閉じると消えます）
- AI・外部APIは使っていません。金額・日付・振込名義の文字の照合と、言い回しの雛形への差し込みだけです
- 「見当たらない」は、貼られた明細との照合の結果です。入っていないと断定するものではありません。連絡する前にご自身の口座で確かめてください
- サンプルは架空の取引先・金額です

## 照合のしかた
- 請求日以降の入金だけを、その請求の入金の候補にします（前の月の入金を取り違えないため）
- 振込名義が書かれた請求は、入金の名義に含まれ、金額が合えば入金ありにします
- 金額が一致する入金があれば入金ありにします。同じ金額の請求が複数あり、入金がそれより少ないときは、どの請求の分か決められないので、すべて「要確認」にします
- 請求額より少ない入金は、設定の差（既定1,100円まで。振込手数料の引かれ分）の範囲で「差額あり（要確認）」にします
- 残りは「入金が見当たらない」です。基準日より前の期日なら期日超過、それ以外は期日前です

## 連絡文
- 超過日数で3段（1〜7日／8〜30日／31日以上）の言い回しになります。強い言い方・期限を切る言い方はしません
- 「すでにお振込みいただいている場合は、行き違いをお許しください」を必ず入れます。振込先は書かず、「請求書に記載のとおり」とだけ書きます
- 期日前の請求には連絡文を作りません

## 限界・未確認
- 実際の銀行の入金明細・請求書ソフトのCSV（列名・文字コード・日付の書き方）では確認していません。サンプル（架空の形式）でのみ確認しています
- まとめ払い、一部入金、源泉徴収などで差し引かれた入金は自動では結びつきません（入金が見当たらない側に出ます）
- iPhone・Androidでの「CSVファイルを選ぶ」とコピーの動作は未確認です
- 連絡文は雛形です。相手にどう受け取られるかは確かめていません
